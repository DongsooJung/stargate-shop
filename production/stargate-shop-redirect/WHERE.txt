이 폴더의 파일은 shop.stargateedu.co.kr 운영 저장소 DongsooJung/stargate-shop-redirect에 넣을 내용입니다.
이 저장소의 index.html과 CNAME은 그 사이트가 아니므로 바꾸지 않습니다.
같은 내용의 패치는 상위 폴더의 stargate-shop-redirect.patch 입니다.
운영 저장소에는 이 실행의 토큰으로 push할 수 없었습니다.

쓰기 권한이 있는 계정에서 운영 저장소를 받은 뒤, 그 저장소 루트에서 패치를 적용합니다.

  git checkout main
  git pull
  git apply --check /path/to/stargate-shop-redirect.patch
  git apply /path/to/stargate-shop-redirect.patch
  git add -A
  git commit -m "fix(shop): 팔 수 없는 가격과 결제 버튼을 닫는다"
  git push origin main

GitHub Pages는 main을 배포합니다. 이 레거시 저장소의 풀 리퀘스트를 머지해도 shop.stargateedu.co.kr는 바뀌지 않습니다.
